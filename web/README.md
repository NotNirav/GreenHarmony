# GreenHarmony AI: Web Application

The web frontend and interactive client engine for GreenHarmony AI. Built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS 4**. The application is compiled as a **100% static export (SSG)** consisting of **515 pre-rendered pages** backed by an offline-ready Service Worker (PWA).

All page data is derived from precomputed JSON generated by `../data-pipeline`.

---

## Quick Start

```bash
# Install dependencies
npm install

# Start development server on http://localhost:3000
npm run dev

# Run full automated test suite (635 tests)
npm test

# Generate production static export (outputs to out/)
npm run build

# Deploy directly to Vercel production
npm run deploy
```

## Automated Test Suite

GreenHarmony features a comprehensive test suite of **635 automated tests** run via **Vitest**:

```bash
npm test
```

- **Solar Physics & Geometry (`space.test.ts`)**: NOAA solar position algorithm, IST solar time, solar altitudes across solstice/equinox, terrace parapet cutoffs, ray-tracing through building obstructions.
- **Planner Rules & Logic (`engine.test.ts`)**: Feasibility checks, pot volume constraints, pet/child safety exclusions, monsoon watering rules, seasonal sun adjustments.
- **Property & Scenario Testing (`quality.test.ts`)**: Monte Carlo evaluation over 400 randomized balcony profiles across all 12 months, extreme climate edge cases (e.g. Shimla frost, Jodhpur heatwaves), weight sensitivity benchmarks.
- **Multilingual Phonetic Search (`search.test.ts`)**: 188 tests covering Devanagari folding, Romanized Hindi/Marathi transliteration, and consonant skeleton matching.

## Architecture & Core Modules

- `src/app/`: Next.js App Router static pages:
  - `/`: Landing page featuring live demo metrics, plant rails, and seasonal highlights.
  - `/plants`: Filterable, searchable plant library with English/Hindi/Marathi search.
  - `/plants/[slug]`: 500 individual pre-rendered plant detail pages.
  - `/plan`: Interactive 8-step Balcony Plan Wizard with real-time 3D solar preview.
  - `/garden`: The Living Garden Dashboard (weather alerts, dynamic watering, layout map, care calendar).
  - `/insights`: Searchable database of 187 gardening tips and micro-insights.
  - `/sources`: Full data credits, taxonomy citations, and photo license references.
  - `/offline`: Offline fallback screen managed by the Service Worker.
- `src/lib/space/`: Balcony geometry and solar simulation engine:
  - `solar.ts`: High-precision NOAA solar position algorithm.
  - `sunmap.ts`: Ray tracer modeling building obstructions, overhangs, and railings.
  - `zones.ts`: Layered growing zones and capacity calculation based on pot dimensions.
- `src/lib/engine/`: Balcony garden planning and intelligence:
  - `recommend.ts`: Feasibility filtering, 100-point scoring matrix, and combination optimizer.
  - `care.ts`: Temperature-adaptive watering schedules and weather hazard alerts.
  - `weather.ts`: Open-Meteo 7-day live weather integration with 3-hour localStorage caching and climate-normal fallback.
  - `impact.ts`: Model-based eco-impact calculations and Garden Harmony Score.
  - `nature.ts`: #EveryPlantCounts community ripple multipliers and achievement milestones.
  - `store.ts`: Zero-backend client storage using LocalStorage and shareable URL state serialization.
  - `useGarden.ts`: Reactive custom hook connecting UI state, solar engine, and planner.
- `src/lib/search.ts`: Phonetic and Devanagari plant search engine.
- `src/components/space/`: Interactive spatial visualization components (`SunStudio`, `SkyView`, `SunHeatmap`, `LayoutView`, `Compass`).

## Progressive Web App (PWA) & Offline Mode

- **Custom Service Worker (`public/sw.js`)**: Implements stale-while-revalidate for static assets, network-first with cache fallback for pages, and a dedicated persistent cache for plant photography.
- **Postbuild Finalizer (`scripts/finalize-sw.mjs`)**: Automatically hashes all static bundles post-build and injects them into the service worker pre-cache list.
- **Installation**: Full PWA support with web app manifest, maskable app icons, and an in-app installation prompt (`InstallApp.tsx`).
